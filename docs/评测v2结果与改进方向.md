> 对应《产品开发规格书-比赛版v-competition.md》§5.1（评测集扩容 n≥30）与 §10 数据源。
> 脚本：`CHAIS/eval_triage_v2.py`（不改动 v0/v1 基线）｜用例：`MDT-5.csv`(真实) + 规格书 §12(4) + `eval_cases_selfbuilt.json`(25)
> 逐例明细落盘：`CHAIS/eval_out/eval_triage_v2_<时间戳>.json`（`eval_out/` 不进 git）

## 1. 评测集构成（n=34，其中参与召回 32 例 + 急症 2 例）

| 子集 | n | 金标准来源 | 可信度 |
|---|---|---|---|
| **真实会诊记录** | 5 | `MDT-5.csv`「会诊专家」列（真实 MDT 会诊记录） | 最高，但量小 |
| **规格书 §12** | 4 | 规格书文档给定的 A/B/C/D 期望行为 | 高（文档定稿） |
| **自建用例** | 25 | 团队按临床常识标注期望科室（`eval_cases_selfbuilt.json`） | 中：**未经执业医师签字确认** |
| 急症（behavior=E） | 2 | G1 拦截正确与否 | — |

**为什么必须分子集报数**：自建用例的写法接近系统输入格式，分数天然偏乐观；
把三类混成一个数字会**高估**真实能力。本文件所有表格都分开列，对外引用时请注明子集。

**局限（如实声明）**：
- 自建用例的期望科室由团队标注，未经过临床医生确认，也没有做双人独立标注；
- 真实子集只有 5 例，单例波动就会显著影响该子集分数；
- 急症用例只验"拦没拦住"，不评价拦截后的处置建议是否最优。

## 2. 结果（纯规则路径 S1+S3，不调用模型）

| 版本 | 子集 | n | Macro 召回 | Macro 精确 | F1 | 全命中 | 平均选科 |
|---|---|---|---|---|---|---|---|
| **改进前** | 真实会诊记录 | 5 | 0.820 | 0.500 | 0.616 | 3 | 6.00 |
| | 规格书 §12 | 4 | 1.000 | 0.713 | 0.818 | 4 | 3.50 |
| | 自建用例 | 23 | 0.783 | 0.659 | 0.696 | 15 | 2.35 |
| | **合计** | 32 | **0.816** | 0.641 | 0.699 | 22 | 3.06 |
| **改进后** | 真实会诊记录 | 5 | 0.770 | 0.467 | 0.576 | 3 | 6.00 |
| | 规格书 §12 | 4 | 1.000 | 0.713 | 0.818 | 4 | 3.50 |
| | 自建用例 | 23 | **0.986** | 0.736 | 0.821 | 22 | 2.65 |
| | **合计** | 32 | **0.954** | 0.691 | 0.782 | 29 | 3.28 |

- **验收**：纯规则 Macro 召回 **0.954**（规格书 §5.1 目标 ≥0.80）→ 达标；
- 对照 v0 旧管线（LLM + 关键词回退）：Macro 召回 0.447 / 0.513；
- 对照 v1（n=9）：纯规则 0.900、完整链路 0.900。
- ⚠️ **真实子集略微下降**（0.820 → 0.770）：新增规则让候选变多，而产品有"最多 6 个方向"的硬上限，
  被裁掉的恰好是真实会诊名单里的支持类科室（康复医学科等）。详见 §4 第 1 条。

### 2.1 三种方法对比（n=34，含模型链路）

| 方法 | 调用模型 | Macro 召回 | Macro 精确 | F1 | 全命中 | 平均选科 |
|---|---|---|---|---|---|---|
| 纯 LLM 选科（对照组：把病历直接丢给大模型） | 是 | 0.944 | **0.388** | 0.524 | 27/32 | **5.50** |
| 纯规则（S1+S3，不调用模型） | 否 | 0.954 | **0.691** | 0.782 | 29/32 | 3.28 |
| **完整链路（S1+S2+S3，本系统）** | 是 | **0.964** | 0.654 | 0.754 | **30/32** | 3.62 |

**怎么读这张表（对外口径）**：
- **召回**：完整链路最高（0.964），纯 LLM 次之（0.944），纯规则 0.954 —— 三者接近，说明**规则层已经能覆盖大部分正确方向**；
- **精确**：纯规则 0.691 ≫ 纯 LLM 0.388（**高 78%**），完整链路 0.654 也远高于纯 LLM ——
  纯 LLM 的"高分召回"是靠**多报**换来的（平均一次报 5.5 个科），患者会被推去一堆科室；
- **结论**：**"规则优先 + 模型受限发言 + 编排校验"在召回不输的前提下，把精确率提高约 70%**，
  这正是把 LLM 放进医疗分诊时必须做的事（宁可少报，不要乱报）。
- 按子集看（同一方法内）：规则/完整链路在**自建集**上召回 0.986 / 1.000，
  在**真实会诊记录**上只有 0.770 —— 差距来自真实长病历的关键词过触发（§4 第 1 条），不是模型能力问题。

## 3. 本轮依据评测**真实修掉**的问题（都有用例号）

| # | 问题（用例） | 根因 | 修法 |
|---|---|---|---|
| 1 | 🔴 **急症漏拦**（SB-E1 突发剧烈头痛+呕吐+意识模糊） | G1 词表只认"意识障碍/意识不清"与"剧烈头痛突发/雷击样头痛"，而"**意识模糊**""**突发剧烈头痛**"两种同义写法都没覆盖 | 补词："意识模糊""嗜睡叫不醒""突发剧烈头痛""剧烈头痛""爆炸样头痛"；按 §风险筛查保守策略**宁可多拦** |
| 2 | 血液科误报（SB-A4 普通上感） | `hema_fever_unknown` 只要求出现"**血常规**"这个词，不要求数值异常 → 化验正常的发热病例也被推给血液科，还把病例撑成 C 型 | 给 `Rule` 增加 `any_of`（与 `all_of` 同时成立的"至少一个"），规则改为"发热 + **血象异常**" |
| 3 | 精神科误报（SB-A4） | 规则关键词含裸词"**精神**"，而"精神可/精神好"是**查体正常描述** | 换成"精神异常/精神症状/情绪不稳/躯体化"等专指词 |
| 4 | 血液科漏诊（SB-A7 血红蛋白 92g/L、SB-B5 血红蛋白 98g/L、SB-C2 淋巴结肿大） | 真实病历写**数值**而不是"贫血/血小板减少"这些词 | 新增**数值型规则**（`pattern`）：血红蛋白 <120g/L、血小板 <100×10⁹/L、淋巴结肿大 |
| 5 | 心血管内科漏诊（SB-C4 血压 176/108mmHg） | 文本只写血压数值，不写"高血压" | 新增数值型规则：收缩压 ≥140mmHg |
| 6 | 泌尿外科全漏（SB-A6 尿频尿急尿痛，原本**一条规则都没命中**） | 规则表缺下尿路症状条目 | 新增泌尿外科三条规则（下尿路症状 / 泌尿系结石 / 前列腺） |
| 7 | 肝胆外科漏诊（SB-D1 胆囊多发结石） | 只认"胆结石"，不认"胆囊…结石" | 关键词补"胆囊/胆道" |
| 8 | 儿科漏诊（SB-A4 "男，4岁"） | 规则只认"儿童/患儿/小儿"这类词，不认年龄 | 新增年龄规则 `(?<![\d])(?:[1-9]\|1[0-4])\s*岁`（负向后顾避免把"58岁"当儿童） |
| 9 | 牵头科不稳定（规格书 C 用例两次跑出不同牵头科） | `_pick_primary` 的最后排序键是**模型置信度** → 两个 strong 科室同分时由模型随机决定牵头，违反"模型只做增量补充"红线 | 排序键改为"规则分 → 规则证据条数 → 牵头倾向 → **科室域次序（确定性）** → 模型置信度"；并加单测：模型给感染科 0.99 置信度也不能抢走血液科的牵头位 |

**顺手统一的界面口径**：A 型（单科为主）病例原来界面写"暂不需要多学科会诊"、后台却仍跑 MDT。
现在 `requires_mdt` 在同步链路与后台相位都生效，报告里那一段写成"（本例以单科为主，未运行多学科会诊）"；
入选方向多于 MDT 上限时，也会如实标注"本次多学科分析覆盖优先度最高的 3 个方向（共 5 个）"。

## 4. 还没解决的（下一轮改进方向）

1. **真实长病历的关键词过触发**（MDT-5 召回 0.25）：真实 MDT 记录里既往史/会诊经过很长，
   我们的规则在整段文本上匹配 → 无关科室被大量命中 → 挤占 6 个方向的名额，反而挤掉了正确的科。
   **方向**：按小节给文本分区加权（主诉/现病史 ×1.0，既往史 ×0.4，会诊经过/查体 ×0.3），
   而不是"整段一起扫"。这也解释了为什么真实子集在加规则后略微下降。
2. **支持类科室天然不牵头/不进前 6**：真实会诊名单里有康复医学科、影像/检验类科室；
   本产品把它们定位为"协同/不牵头"（`DEFAULT_LEAD=0`），所以召回上限就低。
   这是**产品取舍**而非缺陷，但对外报数时必须说明"金标准 = 真实会诊专家名单，含支持类科室"。
3. **手术类映射**（SB-D3 甲状腺结节拟手术漏普通外科）：文本出现"拟行手术"时，
   应结合部位补上外科科室；目前只有心胸外科/超声/麻醉有围术期必选逻辑。
4. **同义词覆盖仍靠人工枚举**：本轮补的 9 条已经说明词表法是"打地鼠"。
   方向：主诉分词 + 医学同义词表（或小模型抽取）替代手工关键词。
5. **急症词表要持续扩**：本轮是靠自建用例撞出来的；建议按"急症主诉清单"系统过一遍
   （胸痛/呼吸困难/大出血/意识改变/剧烈腹痛/孕产妇出血…），而不是等评测用例来发现。
