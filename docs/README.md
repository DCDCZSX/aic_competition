# docs/ —— 设计文档与开发规格（版本化副本）

> 对外品牌：**医序**；完整名称：**医序｜多学科就医信息协作平台**。口号：把复杂资料，变成清楚的下一步。正式项目名称继续使用“多学科就医智助系统”。

> 本目录随代码一起纳入 git 管理，存放**产品设计、开发规格、UI 设计、评测方案与参考资料**。

## 一、同步约定（重要，防两份漂移）

| 项 | 说明 |
|---|---|
| **编辑源** | 工作区 `E:\aic_competition\`（与 `CHAIS/` 同级）下的同名 `.md` 文件 |
| **本目录定位** | 该批文档的**版本化快照**，供队友查看、评审、佐证 |
| **同步时机** | **每次阶段性 PR 之前**，把改过的文档同步到本目录并一起提交 |
| **冲突处理** | 以工作区最新版为准覆盖本目录；**不要直接在本目录改内容**（会被下次同步覆盖） |

> 原因：设计文档在工作区根目录持续迭代，本目录只负责"入库存档"。
