# AI 多学科就医咨询助手（暂定名：MDT 助手）— 产品构想方案

> 状态：PRD 草案 v0.1（用于对齐"我们要造什么"，非最终稿）
> 依据：真实 MDT（多学科会诊）临床流程的线上化再造 + 现有原型升级

---

## 一、产品一句话

> 输入一段病情描述，AI 帮你判断"该看哪些科、要不要多学科会诊"，
> 然后组织各专科 AI 围绕你的情况协同分析，输出一份**可以带去线下就医的结构化会诊参考报告**。

定位红线：**就医决策辅助工具**，不是诊断、不是看病、不给处方；所有结果仅供线下就医参考。

## 二、目标用户与场景

| 场景 | 谁在用 | 痛点 |
|---|---|---|
| 场景 A：**挂科难 / 挂错科** | 症状复杂、不知道挂哪个科的患者/家属 | 百度搜症状越搜越慌；挂错科白排队 |
| 场景 B：**多病共存**（糖尿病+肾病+眼底、慢阻肺+心衰…） | 同时看几个科的慢性病患者 | 各科各看各的，没人帮ta统筹；来回复诊跑断腿 |
| 场景 C：**异地/基层就医前准备** | 准备去大医院的患者 | 不知道要带什么检查、该先看谁，去了白跑一趟 |

**核心价值一句话**：把三甲医院才能组织的 MDT 会诊思路，变成普通患者看病前就能用的"智能参谋"。

## 三、产品功能全景（用户视角）

### 1. 病情录入（第 1 屏）
- 表单式引导 + 自由文本都支持：主诉、现病史、既往史、检查检验结果、用药
- 也可以"直接粘贴一段病历/出院小结"，AI 自动拆字段
- 👉 对应现有原型已有 80%：`medical_history + main_issue` 输入框 → 本方案升级为"结构化录入模板 + 自由文本解析"

### 2. 病例画像卡（新功能，可信度的来源）
- 系统把录入内容抽成一张"画像卡"：症状时间线 / 现病史 / 既往史 / 检查异常值 / 用药过敏
- 列出**信息缺口**（"没提供血糖控制情况""没提供眼底检查"）
- 用户可确认、补漏、改错 —— **先对齐事实，再让 AI 分析**（防幻觉第一道闸）
- 👉 全新，现有原型没有

### 3. 智能分诊与会诊触发（第 2 屏）
- 输出：①最该挂的科室 Top-3（带理由）②是否建议多学科会诊 ③若建议，拟邀请哪些科室、为什么
- 简单病 → 直接给"单科就诊建议"，不硬凑 MDT（诚实）
- 复杂病 → 升级为 MDT 流程
- 👉 现有原型有雏形（controller 选科）→ 升级为"可解释 + 规则/LLM 双通道 + 复杂度判断"

### 4. 多学科会诊直播（第 3 屏，演示的"魔术时刻"）
- 类似"圆桌会议"可视化：被邀请的各科专家卡片**逐条发言**，谁在分析一目了然
- 每科发言都是结构化"意见卡"：本科判断 / 建议 / 需要补充的检查 / 超出本科范围的部分（转给谁）
- 若肾内科说"建议查眼底"，系统自动把这条**转给眼科**继续追问（跨科联动，可见）
- 全程进度条 + 可回看每科发言
- 👉 现有原型是"文字消息流"，升级为可视化会议桌 + 结构化意见卡

### 5. 结构化会诊报告（第 4 屏，最终交付物）
报告自动排版为七个部分，可一键导出 PDF 带去线下：

```
一、病例摘要
二、建议就诊方向（推荐科室 + 理由 + 优先级）
三、各专科意见卡（每科：判断 / 建议 / 所需检查）
四、跨专科提示（会诊中发现的联动线索，如"肾内科建议查眼底"）
五、一致点 / 分歧点（专家意见冲突时如实呈现 + 建议线下专科复核）
六、就诊前准备清单（建议先做的检查 / 要带的资料 —— 提高就医效率）
七、免责声明（固定模板）
```

- 👉 现有原型是"一大段 Markdown"，升级为结构化七段式 + PDF 导出

### 6. 知识引用与历史记录（加分功能）
- 关键建议旁标注"参考来源"（来自内/外科教材的知识点检索）——把闲置的 7MB 教科书用起来
- 历史会诊记录可查、可对比前后变化

## 四、一次典型使用流程（带你走一遍）

**用户**：一位 35 岁女性，反复发热 3 周，血常规异常，怀疑噬血细胞综合征，不知道该看什么科。

**第 1 步**：她在录入页粘贴了出院小结，勾选"主要想搞清楚：噬血细胞综合征的原因？下一步怎么办？"

**第 2 步**：系统生成病例画像卡，提示她"未提供 EB 病毒、自身免疫抗体等检查结果"——她补了一句"关节偶尔痛"。画像确认。

**第 3 步**：分诊结果页显示：
> 建议就诊方向：血液科（优先）、风湿免疫科、感染科
> 系统判断：该病例累及血液系统并疑似免疫因素，建议启动多学科会诊

**第 4 步**：会诊直播开始——画面上血液科、风湿免疫科、感染科、心内科专家卡依次"发言"：血液科分析噬血可能性与需做的检查（EBV-DNA、骨髓活检）；**风湿免疫科提示"关节痛 + 发热 + 血象异常"需排查自身免疫病（如 SLE），并建议查自身抗体**；心内科提示需监测心肌受累……
> 这条"风湿科提示"正是单科 AI 问诊容易漏掉的关键——**这就是 MDT 的价值，也是演示的爆点**。

**第 5 步**：生成七段式报告。用户看到"一致点：需优先完善感染与免疫筛查；分歧点：无重大分歧；就诊前准备：建议先查自身抗体全套、EBV-DNA"。
她把报告 PDF 存下来，挂血液科号时直接给医生看，医生能立刻抓住重点。

## 五、与市面产品的差异（为什么不是又一个 AI 问诊）

| 市面 AI 问诊 | 本产品 |
|---|---|
| 回答"你这是什么病"（单科、一次性问答） | 回答"你该看哪些科、多科怎么协同"（决策辅助） |
| 谁问都一样 | 复杂病例自动组织"多科会诊"，简单病不装 |
| 给一段话就结束 | 给**结构化报告**：就诊方向+各科意见+分歧+就诊前准备清单，能带去线下 |
| 说不清信息来源 | 画像卡先对齐事实；关键建议可引教材来源；分歧如实呈现 |

## 六、创新点（答辩口径，对应"自研部件"）

1. **病例画像事实层**：先结构化、可确认、列信息缺口，再分析 —— 防幻觉的第一道闸（自研）
2. **可解释分诊决策引擎**：规则库 + LLM 双通道，每条推荐带理由（自研）
3. **会诊编排器**：专科角色隔离、越界转诊、跨科联动、分歧如实呈现（自研）
4. **评测驱动迭代**：用真实 MDT 病例金标准量化选科准确率，定位并修复系统缺陷（过程性创新）

## 七、MVP 范围（1 个月版本先做到哪些）

必做：①-⑤（录入→画像卡→分诊→会诊直播简化版→七段式报告 PDF 导出）+ 免责声明
可砍：知识来源引用（⑦）先做"最小版"或不进 MVP
必砍：多轮追问补病史、多用户账号体系、移动端 App（Web 足够）

## 八、演示视频剧本（3-5 分钟，对应第 4 节病例）

1. 痛点 20s：复杂病情不知道该挂哪个科、多病没人统筹
2. 输入 20s：粘贴一段病历 + 提出主要问题
3. 画像卡 20s：AI 抽字段、提示信息缺口（展示"AI 先确认事实"）
4. 分诊 20s：推荐科室 + 触发 MDT + 理由
5. 会诊直播 60s：各科逐条发言，风湿科"跨科提示"是爆点
6. 报告 40s：七段式报告滚动 + 导出 PDF
7. 数据与展望 20s：评测提升曲线 + 未来接入医院/医生端
