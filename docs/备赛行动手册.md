# AI+软件创新 · 备赛行动手册

> 2026 第八届全球校园人工智能算法精英大赛 · 算法创新赛 · 赛题2「AI+软件创新」
> 队伍条件：软件背景、会写代码（无深度 AI 训练经验）、2-3 人、约 1 个月冲刺
> 依据：《2026AIC算法创新赛赛题规则汇总260506-1.pdf》全文 + 往届公开获奖报道调研

---

## 1. 一句话定位

把 AI 算法做成一个**真正能用的软件产品**：需求分析 → 架构 → 开发 → 测试 → 演示 → 文档，全流程都要有。交的是"产品"，不是论文、不是模型。

## 2. 评分表（满分 100，做产品要对着它做）

| 评分项 | 分值 | 高分要点 |
|---|---|---|
| 创新性 | 20 | 有自己的自研部件/独特方案；套壳调 API = 0-6 分档 |
| 技术实现 | 20 | AI 选型合理、跑得稳、交互流畅、模型与软件适配好 |
| 功能完整性 | 20 | 核心功能做完整，主流程端到端能跑，不烂尾 |
| 方案完整性 | 20 | 技术方案文档按大纲写满，架构图/代码/测试齐全 |
| 应用价值 | 15 | 场景明确、解决真实痛点、有真实用户/数据/试点证明 |
| 总结与展望 | 5 | 总结提炼 + 前瞻规划 |

## 3. 必交材料清单（对照检查）

- [ ] 作品名称（≤20 字）
- [ ] 作品简介（≤300 字，按"问题-方案-效果-应用"）
- [ ] 作品方案 PDF（≤10M，模板大纲见规则第 9-10 页）
- [ ] 演示视频（MP4，3-5 分钟，≤300MB）← 评委第一印象
- [ ] 答辩 PPT（转 PDF）
- [ ] 佐证材料（软著/专利/论文/老师试用证明/用户反馈 → 合并 1 个 PDF）
- [ ] 网盘链接（代码包，命名：团队编号-赛题名称-作品名称-XX）
- ⚠️ 红线：所有材料不得出现学校名/Logo/指导教师信息

## 4. 往届国奖调研结论（2024-2025 公开报道）

| 案例 | 成绩 | 它赢在哪 |
|---|---|---|
| 南信大《图鉴天工》遥感影像平台 | 第七届 软件赛道全国第一 | 学校强势学科数据 + 4 个自研部件 + 专利软著 + 基层真实部署 |
| 天大《医图必应》RAG 医疗平台 | 第七届 一等奖 | 2000+ 医患真实调研定题 + 自研 NER/"三级查询优先级"防幻觉 + 社会价值 |
| 中飞院《低空空域飞行程序优化》 | 第七届 算法模型创新一等奖 | 民航特色学科，论文级深度 |
| 华科《植物气孔测量》(UR-CNN) | 第六届 一等奖 | 本校农业科研显微数据 + 自研多任务网络 |

**冠军公式：学校/老师的领域数据 × 自研部件(2-3个) × 完整工程 × 落地证据 × 社会价值叙事**

**推论：我们的复制路径 = "某位老师/某门课/某实验室的真实苦活 + AI 软件化 + 老师当试点出证明"**

## 5. 选题 5 个差异化杠杆（任何想法过一遍，占 2-3 条即可）

1. **真实用户/数据锚点**：绑死一个能触达的具体人群（老师/助教/实验室管理员）
2. **自研部件叙事**：管线里有 1-2 个自己设计的部件（规则引擎/策略/切分器），写进方案和答辩
3. **工程反差点**：私有部署/离线/低成本/数据不出校门——大厂 SaaS 做不到的约束
4. **反直觉小场景**：都做学生工具，就做"服务学生的人"（老师/助教/辅导员/教务）
5. **人机协同**：把 10 步苦活变 1 步轻活，而不是"AI 全自动"（全自动反而假）

## 6. 需求访谈提纲（本周去问 3-5 位老师/助教/实验室管理员）

开场白：我们参加 AI+软件创新大赛，想帮老师做一个真能用的工具，想了解您工作中最耗时最麻烦的环节。

1. 您每周/每学期最花时间、最机械重复的工作是什么？（改作业/出题/审材料/整理数据/回学生消息……）
2. 这项工作现在要几步完成？每一步大概多久？
3. 有没有哪个环节"眼睛累、心也累、还容易出错"？
4. 这些材料/数据现在存在哪？格式统一吗？（Excel？Word？平台系统？）
5. 如果有个工具能自动处理其中一半，您最想要它做哪件事？
6. 您希望它全自动出结果，还是"AI 先做一版、您审核改完再定"？
7. 以前用过类似工具吗？不好用的地方在哪？
8. 这个工具如果做好了，您愿意帮我们试用 2 周、给条反馈吗？愿意的话能开个使用证明吗？
9. 您手里有没有一批可以给我们做实验的**脱敏真实数据**？（历史作业、报告、文档模板等）
10. 您觉得学校/学院里还有谁也有同样的烦恼？

访谈后把答案填到第 7 节评分卡打分。

## 7. 选题评分卡（每项 1-5 分，>24 分可开工）

| 维度 | 问题 | 分 |
|---|---|---|
| 差异化 | 能说清"哪里是我们自研的、别人没有的"？ | |
| 可行性 | 1 个月内能做完整核心功能？AI 链路已有把握？ | |
| 证据可得 | 能找到真实用户/真实数据/试点证明？ | |
| 演示效果 | 3-5 分钟视频里有"魔术时刻"？ | |
| 团队匹配 | 前后端+AI 集成分工有人扛？ | |
| 真实性 | 我们真懂这个场景，不是网上抄的？ | |

## 8. 一个月作战计划

| 周 | 目标 |
|---|---|
| 第 1 周 | 访谈定题 + 技术 PoC（先拆最大风险：AI 效果够不够好） |
| 第 2 周 | MVP 端到端跑通（1 前端 / 1 后端 / 1 AI 管线） |
| 第 3 周 | 功能完善 + 老师试用收集反馈 + 写技术方案文档骨架 + 攒录屏素材 |
| 第 4 周 | 演示视频 → 技术方案 PDF → 答辩 PPT → 佐证材料 → 全材料查重红线 → 提交 |
