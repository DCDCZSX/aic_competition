# 审核分级 Implementation Plan

> **Goal:** 让医生一眼看到必审、建议抽查和自动处理的数量与原因，把高风险、冲突、分析失败和关键路径留在逐条审核范围内。

## 分级口径

- `required` / 必审：默认分级；科室选择、未解决分歧、风险标记、资料缺口、分析失败和明确要求医生处理的路径步骤必须保留在此级别。
- `sample` / 建议抽查：保留为已审核规则的接口，本轮没有新增自动降级规则，因此当前生产病例不会仅凭模型置信度进入抽查。
- `automatic` / 自动处理：只保留原有明确规则，即路径步骤明确标记为不需要医生决定；每项输出 `tier_reason` 和 `auto_reason`。
- 未知分级回退为 `required`，没有理由的项目也显示默认必审理由。
