# MDT 会前资料包 Implementation Plan

> **Goal:** 为医生端生成可快速阅读的 MDT 会前资料包，集中展示初筛目的、参与科室、结构化资料、来源引用、信息缺口、证据关联、专科 AI 参考意见、共识、分歧和处理状态。

## 约束

- 资料包由现有病例 payload 即时生成，不新增完整病史或原始文本持久化字段。
- 当前系统生成的专科分析统一标记为 `ai_reference` / “专科 AI 参考意见”。
- 只有明确由医生端录入且来源已验证的线下意见才标记为 `human_reviewed` / “医生审核内容”。患者转述不升级为医生内容。
- 不显示模型自报置信度、原始模型错误、审核人账号或未脱敏原文。
- 不改变 `case_state`、审核发布门禁或患者端报告结构。

## 实施步骤

- [x] 为专科分析输出增加稳定来源类型和来源标签。
- [x] 在 `report_service` 增加 `build_mdt_preparation_packet()`，从画像、时间线、分诊、证据、初筛、专科分析和聚合结果构建只读对象。
- [x] 将会前资料包挂到医生审核接口返回值，不新增不必要的 HTTP 路由。
- [x] 在医生总览页把资料包放在审核操作入口之前，分区展示初筛、资料缺口、证据引用、AI 专科内容、共识/分歧/缺失状态。
- [x] 增加报告、MDT 分析和前端结构回归测试，先运行失败测试再实现。
- [x] 运行核心回归、前端逻辑、结构检查和 `git diff --check`。
- [ ] 报告渲染工具因当前环境未配置 `APP_PATIENT_PASSWORD` 未完成真实 HTTP 验收。
