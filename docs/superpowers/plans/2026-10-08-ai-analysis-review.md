# AI 分析审核与患者报告预览

经用户确认：报告审核以 AI 关键分析为主；不新增独立患者建议审核步骤，医生填写最终建议后预览并发布。

- [x] 条目：专科推断、待核查判断及 AI 共同意见纳入审核；病例事实、普通准备提示不逐条审核。单专科使用相关预分析，正式 MDT 使用当前有效模拟。
- [x] 覆盖：修改、驳回与暂不确定结果进入报告有效视图，保留原始审计；模拟重生成及资料变更使旧决定失效。
- [x] 发布：保留既有门禁，提供只读患者报告预览；审核、建议或病例变化后须重新预览。
- [x] UI：沿用当前设计，按来源/科室阅读分析，显示依据、正式会诊结论及发布预览。
- [x] 验证：针对分析来源、报告覆盖、过期决定和预览发布写回归测试；桌面及手机完整流程验收。
