# 新增资料后的增量复核 Implementation Record

> **目标：** 新资料进入后，只重新打开受影响的审核项；旧决定继续可追溯，但不能批准已经变化的内容。

## 已完成

- [x] 审核项保留稳定 `item_id`，并从病例 payload 读取 `content_revision`；只有发生变化的已有条目递增修订号，新条目从当前版本开始。
- [x] 审核决定保存 `content_revision`，旧记录缺字段时按第 1 版兼容读取；当前修订只选用同一修订内最后一条有效决定。
- [x] 资料更新结果返回 `affected_item_ids`、`affected_item_labels`、`reopened_item_ids`、`reopened_item_labels`、`affected_departments`、`unaffected_departments` 和 `recomputed_phases`，同时记录新增与移除的审核项。
- [x] 眼底检查等可识别的检查结果按依赖矩阵映射到具体科室；无法识别时保留原有保守的全量检查结果口径。
- [x] MDT 更新只替换受影响的专科意见卡，保留未受影响卡片；新入选科室在分析名额内追加待分析卡。模型不可用时明确标记为等待重新分析，不把旧卡伪装成当前结果。
- [x] 患者变化摘要、医生队列、医生审核页和审核历史展示受影响/重开的具体项目、未受影响科室、内容修订号和过期决定提示。
- [x] 旧决定仍保存在 decisions 表的 JSON 审计记录中；条目消失、内容修订变化或决定修订号不匹配时均标记为 `stale`，不会套用到当前审核结果或发布门禁。
