## 这个 PR 做了什么

分四块，全部有可复跑的验证与可追溯的数字。

### 一、阶段 5.3：五例跨病种验收集 E2E 回归（规格书 §12）

新增 `backend/verify_e2e_cases.py`：A/B/C/D/E 五例走**真实 HTTP + 渐进式链路**，逐例断言
行为类型、牵头科、期望科室覆盖、MDT 卡数（含"最多 3 个方向"的上限口径）、报告 13 段、
免责与能力边界、以及 **AI 文本不得出现诊断结论/概率数字/处方剂量**；E 型急症校验
"400 拦截 + 不生成报告"。`--fast` 模式秒级只验规则首屏。

**结果：52 项断言全过（77.4s）**。它当场抓出两个真实问题（见 §三）。

### 二、阶段 5.1：评测集扩容 n=9 → n=34，三方法对比

新增 `eval_triage_v2.py` + `eval_cases_selfbuilt.json`（25 例自建/合成用例，**无患者隐私**）。
评测集 = 真实会诊记录 5（`MDT-5.csv`「会诊专家」列）+ 规格书 §12 4 + 自建 25，**三子集分开报数**
（合成集分数天然偏乐观，绝不与真实金标准混报）；急症 2 例单独统计拦截率。

| 方法 | Macro 召回 | Macro 精确 | F1 | 全命中 | 平均选科 |
|---|---|---|---|---|---|
| 纯 LLM 选科（对照组） | 0.944 | **0.388** | 0.524 | 27/32 | **5.50** |
| 纯规则（S1+S3，不调模型） | 0.954 | **0.691** | 0.782 | 29/32 | 3.28 |
| **完整链路（S1+S2+S3，本系统）** | **0.964** | 0.654 | 0.754 | **30/32** | 3.62 |

对照 v0 旧管线（Macro 召回 0.447 / 0.513）。**对外口径**：召回不输纯大模型，**精确率高 78%** ——
纯 LLM 的高召回是靠"一次报 5.5 个科"换来的。子集拆分：自建集 0.986/1.000，真实长病历 0.770（原因见结果文档 §4）。

### 三、依据评测修掉的 9 个真实问题（含一个安全漏洞）

| # | 问题 | 修法 |
|---|---|---|
| 1 | 🔴 **G1 漏拦**："意识模糊""突发剧烈头痛"（同义不同语序）都没覆盖 | 补词；按风险筛查保守策略宁可多拦 |
| 2 | `hema_fever_unknown` 只要求出现"血常规"一词 → **化验正常的普通上感也推血液科** | 给 `Rule` 增加 **`any_of`**（与 `all_of` 同时成立的"至少一个"），改为"发热 + 血象异常" |
| 3 | 精神科裸词"精神"误match **"精神可"**（查体正常描述） | 换成"精神异常/精神症状/情绪不稳"等专指词 |
| 4 | **数值型识别缺口**：血红蛋白 92g/L、血小板 43×10⁹/L、血压 176/108 不触发 | 新增 `pattern` 规则（Hb<120、PLT<100、SBP≥140） |
| 5 | 泌尿外科**整类规则缺失**（尿频尿急尿痛一条都不命中） | 新增下尿路症状/结石/前列腺三条 |
| 6 | 胆囊→肝胆外科、7. 儿科年龄、8. 淋巴结肿大→血液科 | 关键词 + 年龄 `pattern`（负向后顾避免把"58岁"当儿童） |
| 9 | **牵头科被模型置信度左右**（规格书 C 用例两次跑出不同牵头科，违反"模型只做增量补充"红线） | 排序键改为"规则分 → 证据条数 → 牵头倾向 → **科室域次序（确定性）** → 模型置信度"，并加单测：模型给 0.99 置信度也抢不走血液科牵头位 |

**顺带统一口径**：A 型（单科为主）病例原来界面写"暂不需要多学科会诊"、后台却仍跑 MDT；
现在 `requires_mdt` 在同步链路与后台相位都生效，报告那一段写成"（本例以单科为主，未运行多学科会诊）"；
入选方向多于 MDT 上限时如实标注"本次多学科分析覆盖优先度最高的 3 个方向（共 5 个）"。

### 四、阶段 5.2：实验三（MDT 增量价值）+ 实验二（专科边界行为）

- `eval_mdt_value.py`（**12 例共病/疑难，同一病例：单科 AI 问诊 vs 本系统 MDT**）：
  MDT 平均**多指出 18.5 条**单科未提及建议（占其产出 48%），**保住单科建议 80%**，
  覆盖 2.67 个专科（单科恒为 1），结构化字段完整率 100%；代价：调用 32 次 vs 12 次、10.2s/例。
  **口径警告已写进脚本与文档**：条数受产出量影响，不能读成"价值高 18 倍"。
- `eval_specialty_boundary.py`（**12 个越界探针**：拿明显属于 A 科的病例去问 B 科）：
  越界时**自知边界率 100%**（给出转诊方向或明确写出缺失信息）、检查项确认式 100%、
  **红线违规 0**、事实可溯源 64%（8-gram 严格近似，口径见文档）。
- ⬜ **未做**：实验二"CMB 专科题库准确率"（需下载题库 + 医学答案核对）、实验三人工 checklist 双盲评分。

### 五、阶段 6.D 收尾：token 单一来源 + 响应式分档回归 + 打印回归

- **token 单一来源**：抽 `static/css/tokens.css`（56 个共享 token），工作台经 `dsh.css` 的 `@import`、
  首页 `<link>` 引入后只保留自己的覆盖（更大的编辑式尺度、`--nav-h:72px`、8 个别名）；
  **程序化验证**：两页由"共享+覆盖"解析出的 token 映射与原文件**逐字节一致**（86/74 个全对）→ 视觉零变化。
- **响应式分档回归**（新增 `tests/test_responsive_layout.py`，自带极小 CSS 求值器，**无需浏览器**）：
  在 1920/1440/1366/1280/1100/992/768/390 **八档**上求值真实样式表，断言"每个关键操作至少有一个可见入口"
  "≥1440 隐藏主区镜像避免同一操作出现两次""<1440 由镜像承接""患者端 ≤1000、医生端 ≤1100 外壳塌成单列"
  "多列区窄屏单列"，以及"页面用到的每个 `var(--x)` 都有定义"。
- **打印回归**：打印档下外壳/操作条/折叠控件隐藏、`details.sec` 还原为完整文档。
